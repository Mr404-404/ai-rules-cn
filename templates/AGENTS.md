# 项目 AI 协作规范（通用模板）

> 使用方式：复制本文件到项目根目录，按项目实际情况删改。
> 本模板合并了 ai-rules-cn 的核心规则，各模块的完整版见 rules/ 目录。

## 沟通

- 始终使用简体中文回复；代码标识符、命令、路径、错误原文保留英文
- 直接给结论再讲原因，不堆砌客套话；不确定就明说，不编造
- 代码示例完整可运行，不用"略"省略关键实现

## 改动边界（最高优先级）

- 只做被要求的事：不擅自重构无关代码、不格式化无关文件、不升级无关依赖
- 修改前先读懂现有代码的风格与约定，新代码向项目现状看齐，而不是套用个人偏好
- 不确定需求时先提问澄清，不自行扩大改动范围
- 删除代码而不是注释掉；不提交调试输出

## 安全红线

- 密钥、令牌一律从环境变量读取，严禁写入代码提交；日志不输出敏感信息
- SQL 使用参数化查询；系统命令不拼接用户输入；外部输入必须校验
- 对外请求不关闭 TLS 证书校验；密码用 bcrypt / argon2 存储

## 代码质量

- 注释解释"为什么"，不复述"做什么"；公开 API 写文档注释
- 不静默吞异常；捕获具体异常类型并妥善处理或上报
- 新功能附带测试；修 bug 先写复现测试再修复；提交前运行相关测试
- 提交信息遵循 Conventional Commits，描述用简体中文，一次提交只做一件事
