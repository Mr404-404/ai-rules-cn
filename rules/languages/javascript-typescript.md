# JavaScript / TypeScript 编码规范

## 语言与模块

- 新项目一律使用 TypeScript；已有 JS 项目跟随项目现状，不擅自大规模迁移
- 模块系统跟随项目现状（ESM 或 CJS），不混用；新文件默认 ESM
- 使用 `const`，需要重新赋值时才用 `let`，禁止 `var`
- 使用 `===` / `!==`，不使用 `==` / `!=`

## 类型

- 禁止显式 `any`；确实无法确定类型时用 `unknown` 并收窄
- 优先使用联合类型与类型守卫，避免类型断言 `as`；必须用 `as` 时附注释说明原因
- 函数参数与返回值显式标注类型；局部变量依赖推断即可
- 禁用 `@ts-ignore`；确需压制错误时使用 `@ts-expect-error` 并说明原因

## 风格

- 优先使用纯函数与不可变数据；数组操作用 `map` / `filter` / `reduce`，慎用原地修改
- 异步统一使用 `async` / `await`，不把 `.then()` 链和 await 混用在同一段逻辑里
- 错误处理：异步函数必须处理 rejection；不允许空的 `catch {}`
- 优先使用解构、可选链 `?.`、空值合并 `??` 等现代语法
- 格式化与 lint 以项目配置（prettier / eslint）为准，不引入与项目冲突的个人风格

## 依赖

- 新增依赖前说明理由，并优先选择零依赖或维护活跃的方案
- 不引入与项目已有依赖功能重复的库（如已有 lodash 就不再引 ramda）
