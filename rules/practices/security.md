# 安全红线

以下规则在任何项目中均为强制项，优先级高于其他编码规范。

## 密钥与敏感信息

- 严禁把密钥、令牌、密码、私钥写入代码或配置文件并提交；一律从环境变量或密钥管理服务读取
- 发现历史代码中已存在硬编码密钥时，立即提示用户轮换该密钥，仅删除代码不算修复
- 日志与错误信息中不得输出敏感信息（密码、令牌、身份证/银行卡号、完整手机号）

## 输入与注入

- 所有外部输入（HTTP 参数、文件内容、环境变量、命令行参数）视为不可信，必须校验与转义
- SQL 一律使用参数化查询或 ORM，禁止字符串拼接 SQL
- 执行系统命令时禁止拼接用户输入；必须使用参数数组形式调用
- 渲染用户生成的内容时防止 XSS；富文本必须经过白名单过滤

## 依赖与文件

- 新增依赖只从官方 registry 安装，不使用来源不明的脚本或二进制
- 文件路径操作必须防范路径穿越（`../`），对外提供的文件下载限制在指定目录内
- 上传文件校验类型与大小，存储路径与文件名由服务端生成

## 网络与加密

- 对外请求默认校验 TLS 证书，禁止全局关闭证书校验
- 密码存储使用 bcrypt / argon2 等专用算法，禁止 MD5 / SHA1 / 明文
- 随机数涉及安全场景（令牌、验证码）时使用密码学安全随机源
